= SKaiNET Embedded Vendors
:description: Vendor-specific SKaiNET compiler plugins — hardware target optimizers that live outside the agnostic core.

Vendor-specific SKaiNET plugins that live *outside* the hardware-agnostic SKaiNET
core and the model definitions. Each plugin registers a hardware target's
optimizations with the SKaiNET `TargetOptimizers` registry; an application selects
a target and installs the matching plugin at its composition root.

The core never names a backend — it only sees a target string and asks the registry
which passes to run. That is what keeps every vendor specific out of core and out of
your model, so the exported StableHLO stays portable.
